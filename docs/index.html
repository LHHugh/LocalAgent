常见问题

接入前你可能想知道的

怎么开始使用？

在定价页填写申请单，说明用途和预估用量，审核通过后邮件发你 API Key，之后就是标准 OpenAI 调用方式。

支持图片输入吗？

支持。content 字段可以传数组，图片项用 image_url，值可以是 base64 data URI 或公网可访问的图片地址。单请求默认最多 1 张图。

上下文有多长？

当前单次请求上限 8192 token。这个值受显存限制，后续会评估上调。

并发和速率有限制吗？

有。按套餐区分 RPM 与并发数，超出会返回 429。具体见文档里的限流说明。

可以私有化部署吗？

可以。Enterprise 档提供私有化部署与定制，交付内容包括镜像、部署脚本与一次培训。

数据会被用来训练吗？

不会。默认不保留请求正文，只记录 token 用量等计费必要字段，审计日志有保留期限。
